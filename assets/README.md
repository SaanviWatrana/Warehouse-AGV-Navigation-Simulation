# Visual Assets

The repository uses a technical robotics visual language derived from the project domain.

## Theme

- Background: `#0B0F14` — near-black
- Surface: `#111827` — charcoal blue
- Primary accent: `#22D3EE` — electric cyan
- Secondary accent: `#8B5CF6` — engineering violet
- Highlight: `#A3E635` — signal lime
- Alert/action accent: `#FF4D8D` — hot pink
- Text: `#F8FAFC` — high-contrast white
- Muted text: `#94A3B8` — slate

The combination is intentionally different from the Fleet Management System repository while retaining a consistent technical portfolio quality.
